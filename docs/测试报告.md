# 金属增材制造自动化工厂测试报告

## 1 背景

随着 AGV 小车的广泛应用，市场对 AGV 产品的适应能力、功能要求、定位精度、承载能力等提出了越来越高的要求，AGV 小车功能呈现多用性发展趋势。AGV 小车集光、电、机、计算机为一体，综合了当今科技领域先进的理论和技术，可以快捷地与各类生产线、装配线等有机结合，可以根据不同的需求，以不同的组合，进而实现各种不同的功能，具有突出的兼容性及良好的适应性。

近年来，金属增材制造行业发展迅速。在增材制造的工业 4.0 中，AGV 小车带来了新的机遇。通过引入 AGV 小车来完成繁琐枯燥的送粉工作，实现金属增材制造的自动化生产，可以显著降低安全风险，促进生产效率。

本测试报告依据《自动化工厂测试计划和用例》，对 AGV 小车的各功能模块进行系统测试，验证其是否满足需求分析报告中的验收指标。测试覆盖从底层驱动（电机、传感器）到上层复合任务（循迹+避障）的完整功能链。

## 3 电机驱动测试（FR-12）

### 3.1 验收指标

1. PWM speed ≥ 2100 时四轮均能可靠转动；
2. PWM speed < 2100 时车轮不转（扭矩不足以克服静摩擦）；
3. `car_diff_turn(left, right)` 正确实现有符号差速驱动；
4. `car_brake()` 能耗制动比 `pwm_car_stop()` 自由滑行停车距离短 50% 以上。

### 3.2 测试原理

电机通过 AT8236 H 桥驱动，TIM1/TIM8 输出 20 kHz PWM。ARR=3599，有效占空比 = CCR/3600。`MOTOR3_REVERSE`/`MOTOR4_REVERSE` = 1 对右前/右后电机逻辑反转（物理接线与代码假设相反）。`car_brake()` 将所有 8 路 CCR 设为 3600（>ARR），PWM1 模式输出恒高，H 桥 A=B=1，电机端子短接，产生最大反电动势电流制动。

### 3.3 测试过程

**3.3.1 最低启动速度测试**

1. 启用 `test_motor` 任务；
2. 小车悬空（车轮离地），逐步增加 PWM speed 值：1800, 1900, 2000, 2050, 2100, 2200, 2400；
3. 每个 speed 值保持 2 s，观察并记录每个 speed 值下四轮是否转动；
4. 将小车放回地面，重复上述测试，确认地面静摩擦下的最低启动速度。

**3.3.2 差速转弯测试**

1. 调用 `car_diff_turn(2850, 2850)` 验证直行；
2. 调用 `car_diff_turn(2850, 0)` 验证右转（右轮停止，左轮前进）；
3. 调用 `car_diff_turn(2850, -1500)` 验证右弧线转弯（右轮反转）；
4. 调用 `car_diff_turn(2850, -2850)` 验证原地右旋（左右轮等速反向）；
5. 调用 `car_diff_turn(-2850, 2850)` 验证原地左旋。

**3.3.3 能耗制动测试**

1. 小车以 `pwm_car_forward(2850)` 全速行驶 1 s；
2. 方式 A：调用 `pwm_car_stop()`（自由滑行），测量从命令发出到完全停止的滑行距离；
3. 方式 B：调用 `car_brake()`（能耗制动），同样测量停车距离；
4. 重复 5 次，计算平均停车距离比。

## 4 循迹测试（FR-01）

### 4.1 验收指标

1. 循迹精度（小车行进 1 m 内偏离黑线中心的距离）达到 2 mm；
2. 小车能在含 90° 弯道的闭合路径上连续行驶 ≥3 圈不脱线；
3. 脱线后能在 3 s 内找回黑线并恢复循迹。

### 4.2 测试原理

AGV 小车通过四路红外对管传感器（PF13/PF14/PF15/PG0）检测黑线位置，加权计算位置误差（−3/−1/+1/+3）。根据误差选择比率档位（ARC/CORNER/SETTLE/SEARCH），通过差速弧线转弯修正方向。PWM slew rate limiter 防止方向反转时的机械冲击。

影响循迹精度的因素：

1. **传感器安装间距**与黑线宽度的匹配度：间距过大→检测盲区，过小→灵敏度不足；
2. **环境光干扰**：阳光含红外成分，会降低传感器对比度；
3. **地面反射率均匀性**：反光不均→传感器基线漂移；
4. **控制周期与车速耦合**：1 ms 周期下，车速越高，两次修正间行进距离越大；
5. **电机响应延迟与机械惯性**：slew limiter 制动/加速步进影响修正响应速度；
6. **非对称去抖滤波**：`IRTRACK_RELEASE` = 3 使白地释放延迟 3 ms，可能在高速度下引入滞后。

### 4.3 测试过程

**4.3.1 直线循迹精度测试**

1. 在平坦地面上贴一条长度 ≥2 m 的直线黑色路径标线（宽度 1.8~2.0 cm）；
2. 将小车放置于黑色路径标线正上方，4 路传感器居中对准黑线；
3. 启动小车，开启循迹功能（`FollowAvoid_Init()`，状态 FA_FOLLOW）；
4. 在黑线上标记 0 m 和 1 m 两点，小车从 0 m 处启动；
5. 小车自动循迹行驶至 1 m 标记处停车；
6. 用精度为 0.1 mm 的游标卡尺测量 1 m 标记处小车中心轴线与黑线中心的偏离距离；
7. 重复 5 次上述实验，取平均值。

**4.3.2 弯道循迹稳定性测试**

1. 贴一条含 2 个 90° 弯道的闭合矩形黑线路径（长约 3 m，宽约 1 m）；
2. 将小车放在黑线上方启动循迹；
3. 观察小车是否能在弯道处平滑转弯不脱线；
4. 记录连续行驶圈数，直到脱线或满 5 圈；
5. 记录弯道处最大偏离距离（目测+标尺辅助）。

**4.3.3 脱线恢复测试**

1. 在直线路径上，小车正常循迹行驶；
2. 人为将小车推离黑线（偏离约 5 cm）；
3. 观察小车是否进入 SEARCH 模式旋转找线；
4. 记录从脱线到恢复循迹的时间；

## 5 超声波测距测试（FR-02）

### 5.1 验收指标

1. 测距范围 2 cm ~ 400 cm；
2. 测距精度 ±3 mm（在 20 cm ~ 100 cm 范围内）；
3. 单次测距周期 ≤60 ms（触发间隔）。

### 5.2 测试原理

HC-SR04 超声波传感器触发流程：PF11 输出 >10 μs 高电平脉冲 → HC-SR04 自动发射 8×40 kHz 方波 → PF12 回波上升沿（DWT 记录 `echo_start`） → 回波下降沿（计算 `elapsed_us = DWT_Micros() - echo_start`）→ 距离计算：

```
distance_mm = (elapsed_us × 5 + 14) / 29    // 四舍五入
distance_cm = (distance_mm + 5) / 10         // mm 转 cm，四舍五入
```

DWT CYCCENT @72 MHz，1 μs = 72 cycles。最大回波 35,000 μs 对应约 6 m 量程上限。触发间隔 60 ms 防止前次回波干扰。

**测距代码片段**：

```c
/* 触发 */

    /* TODO: PF11 = HIGH, DWT_DelayUs(10), PF11 = LOW */
}

/* EXTI 回调 — 上升沿记录起始，下降沿计算距离 */
void Ultrasonic_EXTI_Handler(void) {
    /* TODO: rising → echo_start = DWT_Micros(); echo_active = 1;
       falling → elapsed_us = DWT_Micros() - echo_start;

```

### 5.3 测试过程

1. 将超声波传感器固定于测试台上，正对平整墙面（非吸音材质）；
2. 依次将传感器与墙面距离设为 10 cm、20 cm、30 cm、50 cm、100 cm、200 cm；
3. 每个距离触发 5 次测距，等待 ≥60 ms 间隔，记录读数；
4. 对比实际距离与测量距离，计算误差：`error = |measured - actual|`；
5. 额外测试：在 30 cm 处用手快速挥过，观察是否能检测到近距离物体。

## 6 超声避障超车测试（FR-03, FR-07）

### 6.1 验收指标

1. 小车在检测到前方 ≤15 cm 障碍物时，能在 0.5 s + 测距周期内停车；
2. 距离 ≤30 cm 时循迹速度降为 `FA_LINE_SLOW_SPEED` = 2100；
3. 超车机动流程完整：右超车(OVT1) → 等 2 s(OVT_GAP) → 左超车(OVT2) → 旋转找线(SEARCH) → 恢复循迹(FOLLOW)；
4. 超车过程中不碰撞障碍物；
5. 超车后旋转找线能在 3 s 内找到黑线并恢复循迹；
6. 超车成功率 ≥80%（5 次中 ≥4 次完整完成）。

### 6.2 测试原理

`FollowAvoid` 6 状态机完整流程：

```
FA_FOLLOW ──[dist≤150mm]──► FA_STOP ──[500ms]──► FA_OVT_1
                                                       │
                      FA_FOLLOW ◄──[找到线]── FA_SEARCH ◄──[未找到线]── FA_OVT_2
                                                       │
                  FA_OVT_1 ──[complete]──► FA_WAIT ──[2000ms]──► FA_OVT_2
```

**超车机动细节（`overtake.c` 5 状态）**：

| 阶段 | OVT1 (右超车) | OVT2 (左超车) |
|------|-------------|-------------|
| STOP | 停车 1000 ms，红快闪+蜂鸣 | 停车 1000 ms |
| ROTATE_1 | 原地右旋 500 ms (speed=3000) | 原地左旋 480 ms (speed=3000) |

## 8 综合循迹避障测试（FR-07）

### 8.1 验收指标

1. 小车在含弯道、直道的闭合黑线路径上连续循迹行驶 ≥3 圈不脱线；
2. 遇到路径上的障碍物时，能自动超车避让并恢复循迹；
3. 载重 0.5 kg 砝码时仍能完成上述测试；
4. 小车利用率（开动率 × 性能达标率 × 准确率）> 60%。

### 8.2 测试原理

`FollowAvoid` 综合任务将 `line_follow`（红外循迹）与 `ultrasonic_overtake`（超声避障超车）组合为优先级状态机。正常时 `FA_FOLLOW` 状态运行循迹；检测到障碍物时切换至避障流程。避障期间**暂停循迹**（不调用 `LineFollow_Run()`），超车机动由 `Overtake_Tick()` 驱动。超车完成后进入 `FA_SEARCH` 旋转找线，找到黑线后恢复 `FA_FOLLOW`。

**利用率计算**：
- 开动率 = 正常运行时间（FOLLOW+OVT 状态） / 总测试时间
- 性能达标率 = 达标圈数（不脱线完成） / 总圈数
- 准确率 = 避让成功次数 / 避让总次数
- 利用率 = 开动率 × 性能达标率 × 准确率

### 8.3 测试过程

4. **空载测试**：
   - (a) 观察小车是否连续循迹行驶 3 圈不脱线；
   - (b) 观察遇到障碍物时是否正确执行超车避让；
   - (c) 记录脱线次数、超车成功次数、总运行时间；
5. **载重测试**：
   - (a) 放置 0.5 kg 砝码于车顶中心；
   - (b) 重复步骤 4；
6. 计算利用率。
